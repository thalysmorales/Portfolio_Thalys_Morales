# Portfólio — Thalys Morales

Portfólio pessoal desenvolvido com HTML, CSS e JavaScript, apresentando projetos, trajetória acadêmica/profissional e formas de contato.

🔗 **Acesse:** [_adicione aqui o link do deploy (Netlify, Vercel, GitHub Pages...)_](https://moralesthalys-portfolio.netlify.app/)

## 📸 Sobre o projeto

Site responsivo que reúne:

- Apresentação pessoal com efeito de texto embaralhado (Scramble Text)
- Seção "Sobre Mim" com destaques em cards
- Seção "Projetos" com cards em efeito *flip* (frente/verso) exibindo tecnologias usadas e links para os projetos
- Tooltips interativos nos ícones de ferramentas utilizadas
- Linha do tempo (trajetória acadêmica e profissional)
- Seção de contato com links diretos (WhatsApp, e-mail, GitHub, LinkedIn, Instagram)
- Menu de navegação com indicador de seção ativa (scroll spy) e rolagem suave
- Menu responsivo (hambúrguer) para dispositivos móveis

## 🛠️ Tecnologias utilizadas

- **HTML5**
- **CSS3** (Flexbox, media queries, animações)
- **JavaScript** (Vanilla JS)
- **[GSAP](https://gsap.com/)** — animações, rolagem suave (`ScrollToPlugin`) e efeito de texto (`ScrambleTextPlugin`)
- **[Bootstrap Icons](https://icons.getbootstrap.com/)** — ícones utilizados em toda a interface
- **[Bootstrap](https://getbootstrap.com/)** — base de estilos (bundle JS)

## 📂 Estrutura do projeto

```
├── index.html          # Estrutura das páginas e seções
├── style.css            # Estilização completa (desktop e mobile)
├── interactive.js        # Animações, menu mobile, flip cards e tooltips

```

## ✨ Funcionalidades

| Funcionalidade | Descrição |
|---|---|
| Scroll spy | O link do menu correspondente à seção visível recebe destaque automaticamente |
| Rolagem suave | Navegação entre seções com animação via GSAP ScrollTo |
| Texto animado | O cargo "Desenvolvedor Web" é embaralhado e revelado periodicamente |
| Cards de projeto (flip) | Ao clicar em "Saiba mais", o card gira revelando descrição e tecnologias |
| Tooltips | Ícones de ferramentas mostram uma breve descrição ao serem clicados |
| Menu mobile | Menu em tela cheia, acionado por um botão hambúrguer, com fechamento ao navegar |
